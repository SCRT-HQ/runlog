# What the bot stores

- **The run**: a session in the host's account, its log written by the bot as the host's device, one event per move, each saying the bot rolled, or that a person rolled by hand.
- **The server**: which account claimed it, the host role and channel, the kind of thread and card it chose, and which packs are in its vault.
- **The vault**: the pack's text, in the hosting's bucket, read by the bot to play. The hosting stores the pack text so the bot can run it, but does not distribute that text. The thread receives only drawn results from the run, including when the pack is sealed.
- **Discord data**: user ids, guild ids, a thread id and a message id per run, and the names Discord showed. No tokens, no messages of anyone's.

Releasing a server from the profile, or deleting the account, removes the server's rows and empties its vault. [What the server holds](#guide/stored) lists everything else an account keeps.
