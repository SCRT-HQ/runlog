# Clocks

Some packs time a unit; some limit it. A **stopwatch** counts up from the moment the unit begins; a **timer** counts down from the minutes the pack set. Results can start clocks of their own too: a rest clock after a loading, fifteen minutes for a room.

The digits are big enough to read from across a room and do not jitter. A timer's bar turns to the warning color in its last tenth. **Pause**, **Resume** and **Stop** are moves like any other: undoable, and visible to everyone in a shared run.

## What the log keeps

The log records clock start, pause, resume, and stop events. The app calculates elapsed time from those events, so a running clock survives a reload, another device shows the same time, and the board retains each unit's final time.

When a pack's clock is set to start by hand, the round shows a **Start** button instead of starting on its own. Either way the clock stops when the unit closes, and its time is written once.

## When a timer runs out

The clock stops itself, marked as having run out, and the app plays [an alert](#guide/alerts). A phone buzzes as well.
