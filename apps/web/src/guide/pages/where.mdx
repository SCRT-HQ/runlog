# Where the app runs

| Copy                                          | Sign-in and sync | Everything else       |
| --------------------------------------------- | ---------------- | --------------------- |
| The hosted copy, `runlog.scrthq.com`          | Yes              | Yes                   |
| A file on disk, or `npx @scrthq/runlog serve` | No               | Yes, offline included |
| The GitHub Pages copy                         | No               | Yes, offline included |

Your packs and runs stay in the browser where you created them unless you enable sync. [Running your own copy](#guide/own-copy) says how to put the app at an address of your own, with or without accounts.
