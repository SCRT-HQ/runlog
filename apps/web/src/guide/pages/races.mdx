# Races across devices <Plan tier="plus" />

A **race** is several people playing the same pack from the same seed at once, each in a separate run on their own device. The seed gives everyone the same dice; only each racer's progress travels.

## Starting and joining

On any setup screen, **Start a race** gives you a six-letter code; leave the seed box empty and one is made for you. Anyone with the pack joins by typing it under **Race** on their setup screen, or by opening a link with it.

## While it runs

The side column shows the leaderboard: who has finished, who is furthest along, who is fastest. The one who started the race can mail the code or end the race. **Forfeits**' seeded session is built for this: ten rounds, the same stakes and the same forfeits in the same order.

The **Race** [widget](#guide/streaming) puts the leaderboard on a page of its own.
