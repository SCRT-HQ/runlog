# The header

The strip across the top is the same on every screen.

- The **Runlog** mark opens the welcome page, or your packs in a copy without one.
- **Back to the run** appears while another page is in front of an open run.
- **Packs** always opens [your library](#guide/library).
- **Create** opens the [Designer](#guide/design), where you write a pack of your own.
- **Guide** opens these pages.
- The account menu, called **Menu** while signed out, holds the theme, sign-in or profile, and sync when it is available. On a phone, **Create** and **Guide** move into this menu so the bar stays on one line.

A run has a bar of its own. **Docs** opens the pack's paper, **Undo** takes back the last move and **Settings** holds device and run controls. On a phone this bar opens from the three-dot button beside the run name.
