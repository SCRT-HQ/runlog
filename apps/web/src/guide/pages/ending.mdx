# Ending a run

When the mode allows it, the run offers its endings between units. Each is the pack's own (keep the set, break what you dislike, carry it out the door), and some are only open once you have earned them.

An ended run stays in your [library](#guide/library) with its log, its board and, where the run kept time, its clocks. Open it and use **Export and share → Save the log** to keep its events as a file.
