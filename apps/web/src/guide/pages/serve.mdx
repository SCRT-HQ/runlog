# On your machine

```bash
npx @scrthq/runlog serve                     # http://127.0.0.1:3535/
npx @scrthq/runlog serve --port 8080 --open  # another port; open the browser
npx @scrthq/runlog serve --host 0.0.0.0      # the rest of the network too
```

The package includes the app. This command serves it on a local port without additional software, including when the table has no internet connection. The packs that ship, the Designer and the paper are all there; a newer package is a newer app on the next reload.

Packs and runs live in that browser. Sign-in and sync belong to the hosted address; the served copy has neither. `--dir` points at another build of the app; `RUNLOG_APP_DIR` does the same from the environment.
