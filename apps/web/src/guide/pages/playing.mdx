# Playing a run

A run is one session of a pack. Packs have their own words for the parts (a Firing of Stages, a Day of Blocks), but the shape is the same: a series of **units**, each passing through the pack's **phases**, each phase a step or two.

## Beginning

The setup screen asks for what the mode needs:

- **Mode.** Every pack has at least one. A mode sets the length, and may seed the dice, seat several players, or make the run a moderated race.
- **Seed.** A seeded mode rolls from the seed, so the same seed gives the same run.
- **Players or contestants.** A together mode seats people at one device; a moderated one takes a roster of names.
- **What you need.** Untick anything optional the pack lists that you do not have, and the dice will not ask for it.
- **A name**, optional, for telling this run from the next.
