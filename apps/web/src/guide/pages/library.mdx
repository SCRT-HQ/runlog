# Your library

Press the pack switcher in the header for your **library**: every pack you have, newest played first, with its runs beneath it. Continue a run, start another without disturbing the one that is open, forget a run, or forget a pack and its runs together.

<Screenshot src="library.png" alt="The library: packs as rows, each with its runs listed beneath." caption="The library. The run open on this device is marked." />

## Getting more

**Get more packs** opens [the catalog](#guide/catalog); **Load a pack from a file** takes [a pack from elsewhere](#guide/pack-files). Any run and any pack can be saved as a file from here, which is also how you keep what you care about before clearing a browser.

## Replacing a pack you loaded

A pack of your own takes a newer file on its own row: **Replace from a file**. The pack's id has to match, so a file of some other pack is refused rather than kept beside it, and the runs stay where they are. Each run remembers the version it was played under and reads whatever text is loaded now, the same as a catalog update.
