# Your library

Press **Packs** in the app bar for your library: every pack you have, newest played first, with its runs beneath it. The main action continues the open or newest unfinished run, or starts one when there is nothing to continue. A run has its own **Forget** action.

Open a pack's **More** menu for the management and document actions available to that pack, such as its documents, Stream Deck profile, an unsaved test run or replacement from a file. **Forget pack** is last. It also forgets the pack's runs, so the app asks before doing it.

## Getting more

Under **Add and discover**, **Get more packs** opens [the marketplace](#guide/marketplace), and **Load a pack from a file** takes [a pack from elsewhere](#guide/pack-files).

Setup files are managed under **Settings → Setups**, under **Profile** when you are signed in, where **Load a setup from a file** adds or replaces one. If you choose a setup at the library's pack-file control, the app keeps it there and links you to Settings. Compatible setups still appear under **Advanced** when you begin a run, because that is where you choose what the run starts with.

## Replacing a pack you loaded

A pack of your own takes a newer file from **More → Replace from a file**. The pack's id has to match, so a file of some other pack is refused rather than kept beside it, and the runs stay where they are. Each run remembers the version it was played under and reads whatever text is loaded now, the same as a marketplace update.
