# Runlog in Discord <Plan tier="server" />

The Runlog bot hosts runs in a Discord server of yours: a run lives in a thread, its table card carries the buttons, one person hosts, and everyone in the server watches there and by live link. The packs come from the account that claimed the server, out of its own shelf, and never leave the server's vault: members see the lines the dice draw, not the pack.
