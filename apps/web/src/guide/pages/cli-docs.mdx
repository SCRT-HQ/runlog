# Writing the paper

```bash
npx @scrthq/runlog docs my-game.yaml -o dist/docs
npx @scrthq/runlog docs my-game.yaml -o dist/docs --only rulebook,reference
npx @scrthq/runlog docs my-game.yaml -o dist/docs --md      # Markdown only; --html for HTML only
```

The command generates five documents from the current pack: the **rulebook**, the **quick start**, the **reference card**, the **run log sheet** and the **summary** a marketplace shows; [Documents](#guide/documents) says what each is for. Each comes as HTML, which a browser prints to a PDF with the page breaks and columns already right, and as Markdown for editing or pasting. The app's Designer makes PDFs directly.

## Bundling

```bash
npx @scrthq/runlog bundle my-game.yaml -o dist/my-game.pack.json
```

`bundle` writes one normalized JSON file for a release. Use YAML while authoring and tracking changes in version control.
