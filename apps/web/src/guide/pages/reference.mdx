# Reference

The contracts live in the repository, beside the code that keeps them, rendered by GitHub; one of them is generated. Each is for someone building against it rather than reading along.

| Read | When |
| --- | --- |
| [Writing a pack](https://github.com/SCRT-HQ/runlog/blob/main/docs/authoring.md) | You are writing a pack by hand. The idea, a complete example, every part of the format and when you need it. |
| [The pack format, field by field](https://github.com/SCRT-HQ/runlog/blob/main/docs/reference.md) | You need one field's exact shape. Generated from the schema; never edited by hand. |
| [The stream API](https://github.com/SCRT-HQ/runlog/blob/main/docs/stream-api.md) | You are writing a plugin, a chat command or a second screen: the numbers, the bell, the gestures. |
| [The testing pack](https://github.com/SCRT-HQ/runlog/blob/main/docs/testing-pack.md) | You want to know what the engine-testing pack exercises, or to write fixtures for your own. |
| [Selling from your own backend](https://github.com/SCRT-HQ/runlog/blob/main/docs/selling.md) | You seal copies from a shop of your own: the container, the key, what the app checks. |
| [Runlog in Discord, in full](https://github.com/SCRT-HQ/runlog/blob/main/docs/discord.md) | Every command, what members see, and what the bot stores. |
| [Setting the bot up](https://github.com/SCRT-HQ/runlog/blob/main/docs/discord-bot.md) | You run a hosted copy and want its own bot: the developer portal, the stage, the token, the commands. |
| [How the hosting is built](https://github.com/SCRT-HQ/runlog/blob/main/hosted/infra/README.md) | The API, billing, selling, races, live push, Discord, monitoring, and why each is the way it is. |
