# Running your own copy

Runlog is a static app: everything that plays a game runs in the browser, from a file on disk if need be, and nothing leaves the device unless someone signs in. There are three ways to run your own copy. The first two require no build or AWS account.

| You want                                                              | Take                                                                                                       |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| The app on your machine, offline                                      | [`npx @scrthq/runlog serve`](#guide/serve)                                                                 |
| The app at an address you control, no accounts                        | [the `app/` directory of the npm package, on any static host](#guide/static-host)                          |
| Accounts, sync, tables with company, the marketplace, at your address | [the `hosted/` directory of the repository, deployed to your AWS account over the npm package](#guide/aws) |

All three options use the published `@scrthq/runlog` app. The hosting adds pages to the built app without requiring a fork.

<Note>A copy you run yourself has no plans and no gates; everything the app can do is open to everyone on it.</Note>
