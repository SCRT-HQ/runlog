# TikTok Live

TikTok LIVE Studio can show a widget, and a gift can ask the run for something. Both use the same two pieces as the other pages: the widget address with the live link's token, and the ask address with the run's key.

## The widget, in LIVE Studio

Add a source of the **Link** kind and paste the widget address from the run's **Settings** → **Stream**, copied with **For another machine** ticked: see [the address that works on a stream](#guide/stream-address). Size it in the scene afterwards; a clear background lets the scene show through.

If your account may stream from OBS instead (TikTok's rule at the time of writing: a thousand followers, eighteen or over, a region where it is offered; the server address and stream key are at the foot of the LIVE Center's producer page and change every session), the [OBS page](#guide/obs) applies as it is, browser source and all.

## A gift that asks

To turn a gift into a press, the run has to be taking asks: in **Settings** → **Stream** → **Chat**, **Take asks** makes the key and shows the address to post to. Then in [TikFinity](https://tikfinity.zerody.one/) make a gift rule whose action reaches Streamer.bot through TikFinity's Streamer.bot connection, and in Streamer.bot make the action from [the Streamer.bot page](#guide/streamer-bot): a **Fetch URL** on `~runlogAsk~&ask=Roll&name=%userName%&via=gift` for a spin, or with a move's name in place of `Roll` for a move. Fetch URL only sends a `GET`, so the ask travels in the address rather than a body. A small gift can be a spin and a large one a move; the Chat panel lists the names the pack answers to.

TikFinity also has a webhook action of its own that posts to a URL. Whether it can send the JSON body Runlog wants is a thing to check in the app; the Streamer.bot route is the one this page vouches for. TikFinity's free tier, five actions and events, is enough for a spin and a move.

What becomes of the ask is the host's call, or the table's under **Act on it as it lands**, and the socket says which with an `asked` gesture, so the same Streamer.bot action can thank the gifter in chat once the forfeit is in.

<Note>Nothing here needs a viewer to install anything or to hold an account with Runlog. The gift is TikTok's; Runlog only hears that it landed.</Note>
