# A Stream Deck at the table

Runlog's plugin is in the Stream Deck Marketplace, under **Runlog**. Install it and fourteen actions appear in the action list: Connect, Run, Next action, Press, Roll, Keep rolling for me, Apply setup, Command, Undo, Metric, Clock, Finish the run, Open in the browser, and Install a profile. It needs the Stream Deck app at 7.1 or later.

Profiles come with it, laid out for each deck (Stream Deck, Mini, XL and +). The Runlog profile installs with the plugin. A pack's profile has that pack's moves on keys, its counters and resources on the numbers, and its setups ready to hand out; it arrives the first time your deck follows a run of that pack, and the deck switches to it. A profile Runlog installs is named for the pack with **(Runlog)** after it, so one you imported yourself keeps its own name beside it. **Switch to the pack's profile when a run attaches**, in Connect's settings, turns that off. A pack Runlog ships no profile for, one you bought or wrote yourself, gets one built from the run: the plugin lays it out from what the run publishes, the same way it would from the pack file, and the Stream Deck app asks whether to import it. The deck stands on the Runlog profile until you say yes. You are handed one whenever the Stream Deck app has no profile under the pack's title, so saying no, or deleting the profile later, gets you the offer again next time your deck follows a run of that pack. Where the app does have one, nothing arrives and the deck is left where it is: importing the same profile twice does not replace the first, so asking again would leave you two. A pack from the Marketplace also has its profile on its page, under **Stream Deck profile**: pick your deck, and import the file in the Stream Deck app. A pack in your library, your own or one you bought, has the same row on its card. Once a profile is yours you can rearrange it like any other.

On an XL and a Stream Deck the keys are grouped by where a hand goes. The top left and the left column drive the run: Connect, Run, Undo and Clock along the top, Next, Roll and Finish below them, and the readouts beside Next. The rest of the deck is the pack's: its counters and resources fill the top right, its setups the third row, its moves the bottom row. The page turns sit in the bottom right corner. That arrangement stays put while the pack's keys page, so a key is in the same place on page two as on page one, and a row with cells to spare lends them to whichever of the three has keys left over. An XL has room to pin more of it than a Stream Deck does. A Mini and a + have too few keys to hold a frame at all, so those two lay everything out in one run and page through it. Every profile ends on a page that is not the run's: this guide, a new run, the dock, the pack's rules, Keep rolling for me and Install a profile, in the right two columns around the way back, with Connect and the run still in the corner they hold on every other page.

## Signing in

Every key's settings carry the same account block: the Runlog address, **Sign in**, **Sign out**, **Reconnect**, and a line saying who is signed in. Leave the address alone unless you run a copy of your own.

**Sign in** shows a code and a link. Open the link in a browser, type the code, and you are signed in on the deck; the plugin keeps that sign-in in a file of its own, not in the settings the pages read. Signing in is not connecting: press Connect after.

## Connect

The key says **Connect** while the connection is closed and **Disconnect** while it is open; press it either way. Nothing is open until you press it, and a connection holding no run closes itself after thirty minutes; the key then says _went idle_ beneath Connect. A deck that is following a run stays up however long the stream goes.

Every other key says **Not connected**, with _press Connect_ beneath it, while the connection is off, and **Offline** for the moment it takes to open.

## The run the deck is on

The deck presses through the page that holds the run, so it only ever sees a run that is synced to your account and open on a page somewhere: the app in a browser tab, a [dock](#guide/dock), or a browser source. With nothing synced the keys say **Not synced**; with runs synced but none open, **No run open**.

**Run** names the run the deck is following. Press it to cycle through the runs open to you and pin the next one; its settings list the same runs by name. A pin holds: a pinned run that ends says **That run has ended** rather than moving the deck to whichever run went next. Where one run is open and nothing is pinned, the deck follows that one; where several are open and none is pinned, the keys say **Pick a run**.

## The keys

- **Next action** presses whatever the run is waiting on: rolling the table, carrying on, closing the unit, entering the next. It carries the step's own words. Where the step waits on a checklist it ticks everything and presses the step's own button; where it waits on a name, it takes the first suggestion. Tick **Stop at decisions** in its settings and it leaves both to the page.
- **Press** does the one thing you pick in its settings: a move the pack offers, or a preset answer.
- **Roll** throws the dice the run is waiting on. It needs no settings, and is lit only while a roll is on offer.
- **Keep rolling for me** hands the dice to the run so it throws them itself; press it again to take them back. The key says which of the two the run is on.
- **Apply setup** changes the run's loadout to a setup from your library and hands it out to the tool, set in its settings. The list is your library for the pack's tool; a tool has to be attached to the run for the hand-out to reach it.
- **Command** sends a setup's operations to the tool once, without changing the run's own setup. A warp is the usual one: it moves the player without swapping what the run is holding them to.
- **Undo** takes back the last result. It is lit when there is something to take back and dim when there is not.
- **Metric** shows one number and nothing else: the score, the unit, the last result, the leader, or a counter or resource the pack keeps. Set to a counter or a resource it is a key as well: a press steps it up by one, or puts it at a number, picked under **On press** in its settings; holding it takes one back off. The other four are the run's own arithmetic and take no press. The clock is not on the list: Clock is a key of its own, and no picker offers what a dedicated key already does, unless that key changes with the run the way Next action does. A key you set to the clock before now still shows it.
- **Clock** counts the run's clock down on the key. Press it to pause the clock, press again to resume, and hold it to stop the clock for good. It says **No clock** where the run keeps none.
- **Finish the run** ends the run, and carries the ending it would take. Hold it for a second and a half; a press says no, so the run does not end on a key caught in passing. It says **Not yet** while the run cannot end.
- **Open in the browser** opens one page in your default browser, picked in its settings: the run the deck is following, that run's dock, a new run, this guide, or the pack's rules. The guide opens whether or not the deck is connected. Handing a profile over was on this key once and is Install a profile now; a key still set to it says **Set up**.
- **Install a profile** builds a profile for a pack in your library and hands it to the Stream Deck app to import, whether or not the deck is following a run of it. Its settings list your library twice: **Packs without a profile** first, then **Packs with one (import again)**. Pick one and press the key; the profile is laid out for the deck the key is on and handed to the Stream Deck app. Where the deck happens to be on a run of that pack it is built from the run; otherwise it is built from the pack file on your account, and it carries the pack's shipped setups along with any the deck has seen on a run of that pack, so both come out the same. A pack you have not synced to your account has no file to read, and the key says no: build that one from its card in your library instead. The Stream Deck app imports a second profile for the same pack as a copy rather than replacing the first, so delete the old one if you do not want both; the key says **Imported as a copy** when that is what just happened.

On a Stream Deck +, Next action, Metric and Clock sit on a dial as well as a key. Turning a Metric dial steps through the score, the unit, the last result and the leader. A Clock dial is the clock, and it redraws every second while one is running. Pressing a Metric dial set to a counter or a resource steps it up by one; pressing a Clock dial pauses the clock or resumes it.

A press the run has moved past, or one the page has to take, comes back refused: the key says why for three seconds, then goes back to what it was saying.

## Keeping the page awake

Chrome discards tabs it thinks nobody is looking at, and a discarded tab is a run the deck can no longer see. Keep the run in an OBS dock or a browser source, or exempt Runlog from Memory Saver in the browser's settings.
