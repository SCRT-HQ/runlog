# A Stream Deck at the table

Runlog's plugin is in the Stream Deck Marketplace, under **Runlog**. Install it and fourteen actions appear in the action list: Connect, Run, Next action, Press, Roll, Keep rolling for me, Apply setup, Command, Undo, Metric, Clock, Finish the run, Open in the browser, and Install a profile. It needs the Stream Deck app at 7.1 or later.

The plugin includes profiles for Stream Deck, Mini, XL and +. Its generic Runlog profile installs with the plugin. Bundled packs also have profiles with keys for their moves, counters, resources and setups. When your deck first follows a run of a bundled pack, that pack's profile installs and the deck switches to it. To keep the current profile, turn off **Switch to the pack's profile when a run attaches** in Connect's settings.

For a pack without a bundled profile, including one you bought or wrote, the plugin builds a profile from the information the run publishes. The Stream Deck app asks whether to import it. Your deck stays on its current profile during this import; the plugin does not switch profiles. When the plugin can read the Stream Deck profile folder, it offers the profile again on the next attach if you decline or later delete it. If a profile under the pack's title is already installed, the plugin skips the offer to avoid a duplicate. If the plugin cannot read that folder, it cannot check for an installed profile and offers the build only once per pack.

Profiles Runlog creates have the pack title followed by **(Runlog)**, regardless of whether they came with the plugin, were created by Install a profile, or were downloaded from a pack page. Marketplace listings have a **Stream Deck profile** download: choose your deck and import the file in the Stream Deck app. Packs you own or bought have the same option on their library cards. You can rearrange an imported profile.

On an XL or regular Stream Deck, Connect, Run, Undo and Clock occupy the top left and left column. Next, Roll and Finish sit below them, with readouts beside Next. Counters and resources occupy the top right, setups the third row, and moves the bottom row. Page controls sit in the bottom right. These positions stay fixed as you page through a pack's keys. Spare cells in a row are used for whichever of those groups needs more keys; an XL can show more keys at once.

A Mini or + has too few keys for those fixed groups, so it pages through one sequence of keys. Every deck profile ends with a page for this guide, a new run, the dock, the pack's rules, Keep rolling for me and Install a profile. On an XL or regular deck, those actions sit in the right two columns around the return key. Connect and Run remain in their usual corner on every page.

## Signing in

Every key's settings carry the same account block: the Runlog address, **Sign in**, **Sign out**, **Reconnect**, and a line saying who is signed in. Leave the address alone unless you run a copy of your own.

**Sign in** shows a code and a link. Open the link in a browser and enter the code. The plugin stores your sign-in in its own file, separate from the key settings. Then press Connect to open the connection.

## Connect

The key says **Connect** while the connection is closed and **Disconnect** while it is open; press it either way. Nothing is open until you press it, and a connection holding no run closes itself after thirty minutes; the key then says _went idle_ beneath Connect. A deck that is following a run stays up however long the stream goes.

Every other key says **Not connected**, with _press Connect_ beneath it, while the connection is off, and **Offline** for the moment it takes to open.

## The run the deck is on

The deck sends presses to the page holding the run. The run must be synced to your account and open in a browser tab, a [dock](#guide/dock), or a browser source. With nothing synced the keys say **Not synced**; with runs synced but none open, **No run open**.

**Run** names the run the deck is following. Press it to cycle through the runs open to you and pin the next one; its settings list the same runs by name. A pin holds: a pinned run that ends says **That run has ended** rather than moving the deck to whichever run went next. Where one run is open and nothing is pinned, the deck follows that one; where several are open and none is pinned, the keys say **Pick a run**.

## The keys

- **Next action** presses whatever the run is waiting on: rolling the table, carrying on, closing the unit, entering the next. It carries the step's own words. Where the step waits on a checklist it ticks everything and presses the step's own button; where it waits on a name, it takes the first suggestion. Tick **Stop at decisions** in its settings and it leaves both to the page.
- **Press** does the one thing you pick in its settings: a move the pack offers, or a preset answer.
- **Roll** throws the dice the run is waiting on. It needs no settings, and is lit only while a roll is on offer.
- **Keep rolling for me** hands the dice to the run so it throws them itself; press it again to take them back. The key says which of the two the run is on.
- **Apply setup** changes the run's loadout to a setup from your library and hands it out to the tool, set in its settings. The list is your library for the pack's tool; a tool has to be attached to the run for the hand-out to reach it. Everyone at the table, players and watchers, is told what was handed out.
- **Command** sends a setup's operations to the tool once, without changing the run's own setup. A warp is the usual one: it moves the player without swapping what the run is holding them to.
- **Undo** takes back the last result. It is lit when there is something to take back and dim when there is not.
- **Metric** shows the score, unit, last result, leader, or a pack counter or resource. For a counter or resource, set **On press** to increase it by one or set a chosen value; hold the key to decrease it by one. The score, unit, last result and leader cannot be changed with this key. Use the separate Clock key for a clock. Older Metric keys set to show a clock continue to show it.
- **Clock** counts the run's clock down on the key. Press it to pause the clock, press again to resume, and hold it to stop the clock for good. It says **No clock** where the run keeps none.
- **Finish the run** shows the ending the run would take. Hold it for a second and a half to end the run; a brief press does nothing. It says **Not yet** while the run cannot end.
- **Open in the browser** opens the selected page in your default browser: the current run, its dock, a new run, this guide, or the pack's rules. The guide opens even when the deck is disconnected. Profile installation moved to Install a profile; a key still set to the old option says **Set up**.
- **Install a profile** installs a profile for a pack in your library, even when the deck is not following that pack's run. Its settings list **Packs without a profile** first and **Packs with one (import again)** second. Choose a pack and press the key. The profile is made for the deck containing that key. If the deck follows a run of the pack, the profile uses information from that run; otherwise it uses the pack file in your account. It includes setups shipped with the pack and setups the deck has seen during a run. For a bundled pack, the key switches to its bundled profile instead of creating a new one. The Stream Deck app installs that profile when the deck first follows the pack, and **Installed from the plugin** confirms the result. Pressing the key again restores a deleted bundled profile. A pack that is not synced to your account has no file for this key to read; use the profile download on its library card instead. Importing a profile that already exists creates a copy rather than replacing the first. Delete the old one if you need only one; the key reports **Imported as a copy**.

On a Stream Deck +, Next action, Metric and Clock sit on a dial as well as a key. Turning a Metric dial steps through the score, the unit, the last result and the leader. A Clock dial is the clock, and it redraws every second while one is running. Pressing a Metric dial set to a counter or a resource steps it up by one; pressing a Clock dial pauses the clock or resumes it.

A stale press or a press requiring a response on the page is refused. The key shows the reason for three seconds, then restores its previous label.

## Keeping the page awake

Chrome discards tabs it thinks nobody is looking at, and a discarded tab is a run the deck can no longer see. Keep the run in an OBS dock or a browser source, or exempt Runlog from Memory Saver in the browser's settings.
