# Streaming a run <Plan tier="plus" />

A **widget** is one panel of the run (the scoreboard, the clock, the race leaderboard) on a page of its own that follows the run as it moves. There is no plugin to install; a widget is a web page, and any streaming app with a browser source can show one. New to Runlog on a stream? [A stream run by dice](#guide/stream-why) says what it is for and what to compare it with.

## The widgets

Under **Stream** in the run's Settings, each widget has **Open** and **Copy address**.

- **Scoreboard**: places, points, and marks in a moderated run.
- **Race**: the leaderboard, as each racer's device reports it.
- **Clock**: the unit's stopwatch or timer, large.
- **Step**: the current step, the constraints in play, the latest result.
- **Stats**: the unit, units done, time on the clock where the run keeps one, the score.
- **Trackers**: resources and counters, as bars and boxes.
- **Ticker**: the last few things that happened (dice, results, points, clocks, a tally moving, the unit closing), one line each, newest on top. It hears the table's gestures the moment they happen and reads the rest from the run, so it catches up after being off scene.
- **Everything, stacked**: the panels above in one column, for a single browser source down the side of a scene. It leaves out what the run has nothing for: a scoreboard with nobody on it, trackers in a pack that has none, the race when the run is not in one.

Three more settings travel in the address: a background (clear, so your scene shows through; solid; or none, the words and numbers alone), a theme pinned for the capture, and a size.

## Chat as input

Under **Stream** → **Chat**, **Take asks** makes a key of the run's own and the address a bot posts to. A channel-point redeem, a chat command or a stream deck button then asks the table to take a move the pack offers ("I died", say) or to roll the table that is waiting. The ask lands in an **Asks** panel beside the people, where you press Accept, or, if you have said so, the table takes it as it lands. [Streamer.bot](#guide/streamer-bot) has the redeem field by field; [the stream API](#guide/stream-tools) has the request for a tool of your own.
