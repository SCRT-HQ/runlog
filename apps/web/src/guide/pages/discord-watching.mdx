# Watching

Everyone in the thread sees the card and the lines. The live link the bot posted opens the run in a browser for anyone, no account needed: [a live link](#guide/live-link) like any other, with the run told stage by stage and a place to send a wave back.

## On a stream

The same link feeds the stream widgets, so a run hosted in Discord can be on a stream like any other; see [Streaming a run](#guide/streaming).
