# After the first deploy

The API's secrets are created as placeholders, and a feature whose secret is a placeholder stays off. Fill the ones you use, signed in to the account:

```bash
aws secretsmanager put-secret-value --secret-id runlog/workos/api-key --secret-string "$(cat)"
```

`workos/api-key` is needed for publisher organizations and their members. Sign-in and sync need no secret: the API verifies tokens against the client ids in the configuration. `stripe/secret-key`, `stripe/webhook-secret` and `stripe/connect-webhook-secret` are for plans and selling; `hosted/infra/README.md` walks through Stripe. The Discord bot has secrets of its own: see [Setting the bot up](#guide/bot).

## The marketplace

The marketplace is empty until the packs that ship are listed in it. Make a publisher for your platform from the app's profile, make a command-line key on it, and from a clone of the repository run:

```bash
RUNLOG_API=https://<your domain>/api RUNLOG_API_KEY=<the key> npm run seed:listings
```

Without it the app shows the bundled packs from the build, which is the same list.
